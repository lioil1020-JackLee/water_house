## 警報提醒與監控可靠性修正

- 修正舊房間警報遮蔽新房間警報，以及靜音後新警報未重新提醒。
- 改用 OPC UA 訂閱逐筆處理轉態，搭配分批快照與定期補讀，降低逐點輪詢及跨電腦復歸造成的漏讀風險。
- 保留本機待確認事件，伺服器復歸與其他電腦操作不會清除本機尚未確認的紀錄；重新啟動後仍保留。
- 警報主畫面維持置頂至本機確認，還原最小化視窗並有限次重試；記錄可見性及前景狀態。
- 增加逐點品質、新鮮度與健康顯示；啟動失敗也會通知，監控執行緒異常結束後會重建。
- 新版 watchdog 檢查每 PID heartbeat 與 worker，限定相同路徑及 Windows session；網路重連不觸發重啟風暴。
- 加入警報 JSONL 事件紀錄、持久化待確認資料及有上限的診斷記錄。

## 下載與更新

Windows 建議下載 **water_house-Windows-onefile.zip** 或 **water_house-Windows-onedir.zip**；均包含主程式與新版 watchdog。更新時必須一起替換兩個 EXE。完整步驟見壓縮檔內 `DEPLOYMENT.md`。

新增「確認目前警報並靜音」只確認本機紀錄，不會復歸 PLC。現場復歸仍使用原有房間設定功能。

## 驗證與範圍

包含警報轉態、跨房間提醒、本機確認／復歸隔離、訂閱分派、部分點失敗、工作執行緒復原、打包 EXE 自測及 watchdog 原生測試。實際四台桌面與 OPC 伺服器仍須依 `DEPLOYMENT.md` 完成現場驗收。

無法補回連線前、斷線期間或伺服器佇列已遺失的警報；完整歷史補償需要 PLC／伺服器事件支援。
