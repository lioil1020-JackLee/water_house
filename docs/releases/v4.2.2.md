## 恢復卡片內的單房 Reset

- 修正加入本機待確認紀錄後，卡片 Reset 未同步確認該房警報的回歸。
- 按下與放開的復歸寫入都成功後，只確認操作開始時本機已收到的該房警報。其他房間、其他電腦及操作後的新事件不會一起被確認。
- 寫入失敗會保留待確認並顯示失敗訊息。現場燈號依 OPC UA 警報狀態回報，不會假造已復歸，也不會把警報開關假設為關閉。
- 同一點位的按下／放開寫入依序執行；關閉房間視窗時也會送出放開，移除關閉視窗後再次送出未配對 Reset True 的舊流程。
- 右上角保留「確認所有警報」，確認本機全部待確認並靜音，不寫入 PLC。
- 保留通訊連續異常 60 秒才提示、即時房間警報、歷史紀錄、喇叭與 watchdog 圖示。

四台請整包更新主程式與 watchdog，保留 `%LOCALAPPDATA%\WaterHouse\` 的警報紀錄。完整更新及單房／全確認現場驗收方式見壓縮檔中的 `DEPLOYMENT.md`。伺服器接受寫入不等於已證明現場壓扣解除，仍須核對實際燈號與 PLC 回報。
