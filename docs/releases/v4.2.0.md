## 隨時可查的本機歷史警報

- 主畫面改為「警報紀錄」，沒有未確認警報時也能開啟。
- 使用程式自己的 Python／Qt 表格視窗，顯示房間、發生時間、復歸紀錄、確認時間及來源，均以臺北時間呈現。
- 支援全部／未確認、房號搜尋與重新整理；讀取在背景進行，不會因查歷史而暫停監控。
- 本機確認後仍保存歷史；查看、篩選或關閉表格都不會確認警報或寫入 PLC 復歸。
- 以本機 SQLite 保存事件、保留跨程式重啟的穩定事件身分，並可匯入仍存在的舊警報日誌。缺少的歷史與時區不補造。

## OPC UA 更新時間診斷

- 要求值保持取樣 100 ms、發布 200 ms、每點通知佇列 128 筆；每輪批次補讀完成後等待 2 秒。
- 增加伺服器真正核定的取樣／發布／佇列值，以及補讀耗時、實際週期等診斷。健康文字提示與診斷日誌分開顯示要求值與核定值。
- 100／200 ms 不能當成已確認的現場速度；Kepware 與 PLC 的上游掃描設定仍會影響實際警報反應。

Windows 請一起更新主程式與 watchdog，完整步驟見壓縮檔內 `DEPLOYMENT.md`。各台只保存本機實際收到的歷史，不能回補斷線期間、連線前已復歸或舊版未保存的事件；本版未修改現場 PLC 或 Kepware 設定。
